# Morpheus Features

Features are feature/epic-level build packages. This folder intentionally follows the Morpheus 2 pattern because that workflow has been useful in practice.

Each feature generally maps to a Jira Epic.

## Expected Feature Shape

```text
features/<feature-slug>/
  README.md
  PRD.md
  TDS.md
  changelog.md
  SDD/
  jira/
  test-plan.md
  artifacts/
```
