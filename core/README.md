# Morpheus Core

Core contains approved shared standards, setup guidance, templates, and governance notes.

Core does not contain generated project documentation or feature artifacts.

## Belongs Here

- setup prompt guidance
- approved shared conventions
- promotion rules
- reusable templates
- high-level governance

## Does Not Belong Here

- feature PRDs or TDS docs
- discovery output for one project
- release notes for one release
- local experiments
- unreviewed skills
