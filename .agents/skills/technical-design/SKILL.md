# technical-design

## Purpose

Create a technical design specification that maps PRD requirements to architecture, decisions, implementation specs, and test strategy.

## Inputs

- `features/<feature-slug>/PRD.md`
- `initiative/constitution.md`
- `initiative/repo-index.md`
- discovery artifacts

## Output

- `features/<feature-slug>/TDS.md`

## Required Content

- architecture integration
- data/API/UI/security impacts as applicable
- decisions and tradeoffs
- traceability matrix
- SDD handoff
- developer test checklist
