# constitution

## Purpose

Create project-level law from actual project evidence.

## Inputs

- `initiative/repo-index.md`
- discovery artifacts
- conflicts report
- existing product-repo agent assets

## Output

- `initiative/constitution.md`

## Rules

- One rule per bullet.
- Cite the source file or discovery artifact for every rule.
- Preserve unresolved conflicts instead of silently choosing.
- Keep preferences out of the constitution unless they are true stop lines.
