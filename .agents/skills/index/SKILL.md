# index

## Purpose

Create a concise navigation map so agents know where to find project facts without rediscovering the repository every session.

## Inputs

- `initiative/discovery/inventory.md`
- `initiative/discovery/intent-map.md`
- `initiative/discovery/architecture-map.md`
- `initiative/conflicts-report.md`

## Output

- `initiative/repo-index.md`

## Required Sections

1. Project at a glance.
2. Workspace folders and repo roles.
3. Where to look up common concerns.
4. Stable anchors into existing docs and agent assets.
5. Glossary and naming drift.
6. Out-of-scope notes.
