# test-plan

## Purpose

Create a test plan that connects feature requirements to developer checks, QA checks, release readiness, and evidence.

## Inputs

- `features/<feature-slug>/PRD.md`
- `features/<feature-slug>/TDS.md`
- `features/<feature-slug>/SDD/**`
- `initiative/constitution.md`

## Output

- `features/<feature-slug>/test-plan.md`
- evidence folder guidance under `features/<feature-slug>/artifacts/`
