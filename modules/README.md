# Modules

Modules are simple workflow descriptions. They explain which approved skills belong together and in what order.

This folder is intentionally flat. Do not recreate category folders such as `domains`, `integrations`, `stacks`, or `workspaces` until real usage proves they are needed.

## Current Modules

- `morpheus-initiation` - project setup and high-level understanding.
- `prd-to-jira` - feature documentation through Jira-ready work.
- `github` - branch, commit, and PR standardization.
- `local-launch` - OS-aware local launch setup.

Each module folder should contain only a README until the workflow has matured enough to need more.
