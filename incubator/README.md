# Incubator

The incubator holds skills and modules that are useful source material but are not approved as ready-to-run Morpheus assets yet.

Use this area for:

- inherited skills that need to be made agnostic
- project-specific skills being prepared for promotion
- partially wired modules that need evidence, tests, or configuration
- review packages for future approved Morpheus Core assets

Do not advertise incubator assets as setup-ready. A candidate graduates only after agnostic review, security review, evidence, documentation, and module-owner approval.
