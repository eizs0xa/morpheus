# Candidate Skills

These skills are preserved for future porting but are not currently approved as ready-to-run Morpheus skills.

Before promotion to `.agents/skills/<skill-name>/SKILL.md`, each candidate needs:

- clear trigger description
- project-agnostic wording
- no hardcoded project names, repo paths, people, Jira boards, or field IDs
- documented inputs and outputs
- evidence from at least one real usage
- validation notes
- security and secret-handling review
- module-owner approval
