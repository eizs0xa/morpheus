# Agent Guidance

When working in this Morpheus repo, keep the structure simple and human-readable.

## Rules

- Approved skills live in `.agents/skills/`.
- Unready skills live in `incubator/candidate-skills/`.
- Project-level docs live in `initiative/`.
- Feature-level docs live in `features/`.
- Release docs live in `releases/`.
- Do not recreate category folders such as `domains`, `integrations`, `stacks`, or `workspaces` unless the user explicitly asks.
- Do not add schemas, profiles, tests, or automation just because they seem useful.
- Do not ask for secrets in chat.

## Current Direction

Morpheus should evolve from Morpheus 2, Morpheus 3, and real project usage. Prefer small, proven workflows over speculative platform architecture.
