# Morpheus Initiative

Initiative is the project-level landing zone.

It aligns to a Jira Initiative or equivalent project container. Discovery, constitution, project scope, project decisions, and generated high-level project docs belong here.

## Expected Contents In A Project Workspace

```text
initiative/
  README.md
  overview.md
  scope.md
  constitution.md
  changelog.md
  repo-index.md
  conflicts-report.md
  discovery/
  docs/
  artifacts/
```

## Skills That Write Here

- `discovery`
- `index`
- `constitution`

Feature and release artifacts do not belong here unless they summarize project-level state.
